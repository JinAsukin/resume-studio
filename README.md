# 简历工坊 Resume Studio

**填写即排版，一键出成稿。** 一个离线、零依赖、单文件的简历生成器 —— 双击打开就能用，数据只待在你自己的浏览器里。

```
填写 → 实时 A4 预览 → 导出 PDF / Word / 网页
```

---

## 特性

| | |
|---|---|
| **所见即所得** | 左栏填、右栏 A4 实时预览，改一个字立刻看到效果 |
| **单页守门** | 底部状态条实时显示页数；一旦超出 1 页立刻标红，并告诉你该精简哪个板块 |
| **三路导出** | PDF（浏览器打印，像素级保真）· Word（自研 OOXML，可直接编辑）· 网页（自包含单文件） |
| **成稿检查** | 10 条规则自动体检：必填缺失、量化成果没加粗、时间格式混用、要点过长…… |
| **通用结构** | 板块只有 4 种类型，教育 / 实习 / 项目 / 志愿 / 学术 / 自雇都能装，不预设你是什么身份 |
| **多版本** | 同一份数据派生多个投递版本（如「通吃版 / 技术方向版」），只记录差异，不复制数据 |
| **主题自定义** | 主色、字号、字体可视化调节；主题可导出成 JSON 分享给他人 |
| **旧简历导入** | 拖入 `.docx` 或粘贴文本，自动识别姓名 / 联系方式 / 板块 / 条目，直接填进表单 |
| **证件照** | 点击、拖入、`Ctrl+V` 粘贴三种方式；自动裁成 3:4 并压缩，尺寸可在主题里调 |
| **真离线** | 单文件、零网络请求、无账号、无追踪。断网也能用 |

## 快速开始

1. 下载 `dist/resume-studio.html`
2. **双击**，用浏览器打开（Chrome / Edge / Firefox 均可）
3. 左侧填写 → 右侧确认版式 → 点「导出」

首次打开会载入一份**虚构人物示例**（林知远 / 云岭大学），方便你直接看清结构。要清空就点「更多 → 新建空白简历」。

### 从旧简历开始（推荐）

点 **更多 → 从旧简历导入**：

- 把 **`.docx`** 直接拖进弹窗
- 或者：打开旧简历 → `Ctrl+A` 全选 → `Ctrl+C` → 粘贴进弹窗 → 点「解析文本」

解析器会识别姓名、联系方式、求职意向、板块结构、条目与各条要点，直接填进编辑器。**全程本机完成，文件不上传。**

> **为什么不直接拖 PDF？** 中文 PDF 的字体编码复杂（CID 字体 + ToUnicode CMap），硬解析错误率高，还会把体积从 125KB 撑到 1.5MB 以上。
> 让 PDF 阅读器负责解码、你负责粘贴 —— 结果反而更准，而且对**扫描件、截图里的文字**同样有效。
> 旧版 `.doc` 同理：请先用 Word 另存为 `.docx`。

> 解析是启发式的：结构规整的简历能还原到八九成，格式花哨的可能需要手动微调。
> 但它至少帮你把文字从旧文件里搬出来了 —— 比对着空白表单从零填快得多。

## 内联标记：用 `**` 强调

要点里写 `**130+**`，渲染出来就是 **130+**（加粗）。

简历里**加粗是给 HR 扫读用的**——把它留给数字和结果：

```
独立触达 **130+** 家企业，面向企业负责人与中高层开展陌生拜访
三次调研累计产出调研报告约 **3 万字**
```

## 导出说明

### PDF（推荐投递用）

点击「导出 → PDF」，浏览器会弹出打印窗口：

- 目标打印机选 **「另存为 PDF」**
- **边距选「无」**（版面已自带页边距，选默认会导致双重留白）
- 勾选 **「背景图形」**（否则意向条与标签行的底色会丢失）
- 值得的话关掉「页眉和页脚」

文件名会自动带上你的姓名。

### Word（网申系统要求 .docx 时用）

生成的 Word 文档结构完整、可继续编辑，含证件照与项目符号。字号使用 Word 语义单位（磅），因此在 Word 里的观感与网页预览**不会完全逐像素相同**——这是 Word 与浏览器排版机制不同导致的，属正常现象。

### 网页（分享用）

导出一份自包含 HTML：样式内联、图片内联、**数据副本也嵌在文件里**。发微信、丢 U 盘、挂静态托管都能直接打开。它同时也是你的备份——哪天浏览器数据清了，重新导入这份 HTML 里的数据即可。

## 成稿检查规则

点顶栏「检查」运行。默认开关如下：

| 编号 | 规则 | 级别 | 默认 |
|---|---|---|---|
| C1 | 内容超过 1 页（简历硬伤） | 🔴 红 | 开 |
| C2 | 必填项缺失（姓名 / 联系方式 / 求职意向） | 🔴 红 | 开 |
| C3 | 量化成果没加粗 | 🟡 黄 | 开 |
| C4 | 时间格式混用（`2023.09` 与 `2023 年 9 月`） | 🟡 黄 | 开 |
| C5 | 单条要点超过 60 字 | 🟡 黄 | 开 |
| C6 | 单个条目要点超过 5 条 | 🟡 黄 | 开 |
| C7 | 板块显示中但没有内容 | 🟡 黄 | 开 |
| C8 | 证件照体积偏大 / 未上传 | 🟡 黄 | 开 |
| C9 | 命中你的「敏感低分项」关键词表 | ⚪ 灰 | **关** |
| C10 | 应届生简历的教育板块位置建议 | ⚪ 灰 | **关** |

> C9（如 GPA、排名、"完访率"这类你不想写纸上的内容）与 C10 默认关闭 —— 工具不该替你决定策略。需要时在 `src/core/lint.js` 的 `config` 里打开并填关键词。

## 数据与隐私

- 所有数据保存在**你自己浏览器的 localStorage**，不上传任何服务器，本软件**没有任何网络请求**。
- 「更多 → 备份数据」可导出 `.json`，换电脑、换浏览器时导入即可。
- 导出的 HTML 里嵌了数据副本，它本身就是一份可恢复的备份。
- 隐私模式或某些浏览器下 localStorage 可能不可用，此时顶栏会提示「本机存储不可用」——软件仍可正常使用，只是刷新后内容不保留，请及时导出备份。

## 从源码构建

```bash
# 1) 同步样式为 JS 常量（改过 document.css 后需要执行）
node tools/sync-css.js

# 2) 校验内核（生成 dist/_preview.html 与测试用 docx）
node tools/selfcheck.js

# 3) 打包成单文件 dist/resume-studio.html
node tools/build.js

# 4) 校验构建产物（结构完整性 / 无外链 / 隐私红线）
node tools/verify-build.js
```

> `tools/verify-docx.py` 是**可选的**产物校验脚本，用 Python 标准库独立验证导出的 docx 是否满足 OOXML 规范（ZIP 完整性、XML 可解析、图片关系一致）。它**不参与软件运行**，不需要它可以直接删掉。

## 设计要点（给二次开发者）

1. **板块只有 4 种类型** —— `entry`（条目型）/ `kv`（键值型）/ `list`（纯列表）/ `text`（纯文本）。教育、实习、项目、竞赛、志愿全部复用 `entry` 的渲染。这是通用性的全部秘密，**不要为某个职业新增类型**。
2. **字段名不含职业预设** —— 叫「条目名称 / 时间 / 补充说明 / 要点」，不叫「公司名 / 职位」。一旦写死，非就业路径的用户就没法填。
3. **HTML 与 DOCX 共用设计令牌** —— `tokens.js` 是唯一真相源，两个渲染器分别把同一组值翻译成 CSS 变量与 Word 单位。**不要各写一套字号**，否则两份版式必然漂移。
4. **强调用内联标记而非结构化数组** —— 手写方便、导入导出无损。
5. **版本用 `overrides` 差量** —— 避免"改了主数据、五个版本全不同步"。
6. **导出 PDF 不走无头浏览器** —— 交由用户浏览器打印，见 `docs/使用说明.md` 的说明。
7. **解析靠规则表，不靠模型** —— `parse-text.js` 里的 `SECTION_KEYS` / `NOTE_HINT_RE` / `ORG_HINT_RE` 就是全部"智商"。想做适配某行业的解析，改规则表即可，不需要动算法。
8. **解析器的判据要能区分同形不同义** —— 例如「某某大学计算机协会 — 硬件部长：面向全校…」是新条目，而「严格执行标准化访问流程：企业信息核验…」是要点。因此判据是**冒号前是否含组织名或破折号**，不是简单的长度阈值。改这里时请先想清楚反例。

## 常见问题

**PDF 导出后两边留白太多？**
打印窗口的边距没选「无」。版面本身已含 46px 左右边距。

**Word 打开和我网页上看到的不一样？**
正常。Word 用磅、浏览器用像素，且断行规则不同。两者都以「单页内、层级清晰」为准，不追求逐像素一致。

**内容超出一页怎么办？**
按状态条提示精简它点名的那个板块；或把「专业技能」的 5 行并成 3 行；或微调主题里的整体字号（缩到 96% 常常刚好救回一页）。

**数据会丢吗？**
存在本机浏览器里，清浏览器数据/隐私模式会丢。建议定期「导出 → 备份数据」。

**导入旧简历后板块串了 / 要点跑到别的条目下？**
启发式解析对格式规整的简历准，对多栏排版、文本框排版的会打折。直接拖板块调整、把要点剪切到正确位置即可；如果某个板块识别错了类型，用板块右上角的下拉改类型。

**拖 PDF 进来没反应？**
有意为之。请打开 PDF 全选复制，粘贴到弹窗的文本框里 —— 这样比硬解析 PDF 准得多，扫描件也能用。

**照片传上去变糊了？**
会自动压成 420×560 的 JPEG（约 100–200KB）。证件照在这个尺寸下打印足够清晰，且能让 Word 文件保持轻量。觉得小可以在「主题 → 证件照尺寸」里改大。
