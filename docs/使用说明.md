# 简历工坊 · 使用说明

> 面向使用者。想改代码请看 [README](../README.md)。

---

## 一、打开与启动

双击 `resume-studio.html`，用浏览器打开。

- 推荐 **Chrome / Edge**（导出 PDF 的打印设置最完整）
- Firefox 同样可用
- 首次打开会载入**虚构人物示例**，看清结构后点「更多 → 新建空白简历」重来

无需安装、无需联网、无需注册。

## 三、从旧简历导入

不想从零填？先让软件帮你把旧简历拆开。

点顶栏 **更多 → 从旧简历导入**，然后二选一：

| 方式 | 操作 | 适用 |
|---|---|---|
| 拖文件 | 把 `.docx` 拖进弹窗 | Word 简历 |
| 粘贴文本 | 打开旧简历 → `Ctrl+A` → `Ctrl+C` → 粘贴 → 点「解析文本」 | PDF、网页、微信、扫描件 |

解析完成后会先给你一份**识别结果**：姓名、联系方式、识别到哪些板块、每个板块几项。确认无误再点「应用到编辑器」。

**全部在本机完成，文件不会上传到任何地方。**

### 为什么 PDF 要手动复制？

不是偷懒，是有意的：

- 中文 PDF 用 CID 字体 + ToUnicode CMap 编码，直接硬解析错误率高（乱码、丢字）
- PDF 阅读器早就把解码做好了，你复制出来的就是干净文本
- 顺带还能**救回扫描件和截图里的字**——直接解析 PDF 对这类文件完全无能

旧版 `.doc` 同理：请先用 Word 另存为 `.docx`。

### 解析结果不准怎么办

启发式解析对**结构规整**的简历（标题独立成行、时间在右侧、要点带项目符号）效果最好；多栏排版、文本框排版的会打折扣。

| 现象 | 处理 |
|---|---|
| 某个板块没被识别 | 用「＋ 添加板块」补上，把内容粘进去 |
| 板块类型不对（该是列表却是条目） | 用板块右上角的下拉改类型 |
| 要点跑到了别的条目下 | 剪切粘贴到正确的条目里 |
| 姓名被识别成了别的 | 直接在「基本信息」里改 |

改完记得点顶栏「检查」再跑一遍。

## 四、填写技巧

### 要点一行一条

所有多行输入框都是**一行一条**。从旧简历、备忘录里整段复制粘贴进去，软件自动拆成条目：

```
独立触达 **130+** 家企业，面向企业负责人与中高层开展陌生拜访
在企业调查高拒访背景下，参与完成小组 20 余份有效问卷
严格执行标准化访问流程，保障数据真实、完整、可追溯
```

### 加粗给谁看

`**文字**` 表示加粗。**加粗名额留给数字和结果**，那是 HR 三秒扫读时唯一会停下来的东西：

| 建议加粗 | 不要加粗 |
|---|---|
| `**130+**` 家企业 | 公司全称 |
| `**3 万字**` | "负责""参与"这类动词 |
| `**队长**` | 常规职责描述 |

### 字段怎么填

| 字段 | 说明 |
|---|---|
| 条目名称 | 学校 / 单位 / 项目名，可含加粗标记 |
| 时间 | 统一格式，推荐 `2023.09 – 2027.06`（检查规则会盯格式混用） |
| 补充说明 | 一行小字，如「主修：社会研究方法、社会统计学」 |
| 要点 | 一行一条，写结果不写职责 |
| 板块导语 | 板块标题下的灰色斜体小字，如「三次调研累计产出约 **3 万字**」 |

### 换个板块类型

每个板块右上角有类型下拉：

| 类型 | 用于 |
|---|---|
| `entry` | 教育、实习、工作、项目、竞赛、志愿、田野……（带时间与条目的都归它） |
| `kv` | 专业技能、证书、语言（左分类右内容） |
| `list` | 证明材料、成果清单（纯条目） |
| `text` | 自我评价、补充说明（整段文字） |

**切换类型会重置该板块内容**，操作前想清楚。

### 证件照

三种插入方式，随便挑：

| 方式 | 操作 |
|---|---|
| 点击 | 点左侧照片框 |
| 拖入 | 把图片文件直接拖到照片框上 |
| 粘贴 | 截图或复制图片后按 `Ctrl+V` |

插入后会自动裁成 **3:4** 比例、压成 JPEG（约 100–200KB），并在框下显示当前规格（超 300KB 会标黄提醒）。

想调大小：**主题 → 证件照尺寸**（小 / 中 / 大）。改完**网页预览和导出的 Word 会一起变**——两边尺寸是联动的。

> 建议：正面免冠、背景干净、脸占三分之二。原图多大都行，软件会处理。

### 板块管理

每个板块右上角：`显示` 开关 · `↑` `↓` 排序 · `×` 删除。
关掉的板块不进入简历，但内容保留——投不同岗位时开开关关即可。

## 五、多版本投递

同一份数据可以派生多个投递版本，只记录差异字段。

- **新建版本**：点顶栏「版本 → ＋ 新建版本」。会复制当前视图，但实际只存差异。
- **改差量**：切换版本后，直接改「求职意向」「个人简介」这类字段，改动**只写进当前版本**；没被覆盖过的字段改动则所有版本共享。
- **管理差量**：「版本 → 管理版本与差量」，能看到当前版本覆盖了哪些字段，可逐条移除。

典型用法：一个「通吃版」放宽口径意向，一个「技术方向版」把意向和简介换成对应的说法，其余经历完全共享。

## 六、主题自定义

点顶栏「主题」：

| 项 | 说明 |
|---|---|
| 主题主色 | 影响标题、板块标题竖线、意向条、分隔线。深蓝最稳，投国企/体制内别用花哨色 |
| 整体字号 | 88%–114%，一刀切缩放全部文字。**内容差一点点溢出时，调到 96% 常常刚好救回一页** |
| 分级字号 | 六层各自独立调整，用法见下 |
| 正文字体 | 微软雅黑 / 思源宋体 / 思源黑体 / 系统默认 |
| 证件照尺寸 | 小 / 中 / 大，改完网页预览与导出的 Word 同步变化 |

### 分级字号怎么用

六个层级从大到小，每级一个滑块：

| 级别 | 管哪些内容 | 默认 | 什么时候动它 |
|---|---|---|---|
| 姓名 | 姓名 | 25 px | 名字较长显得挤时缩小 |
| 头部信息 | 一句话定位、联系方式、意向条 | 12 px | 顶部太占地方，想给正文腾空间 |
| 板块标题 | 教育背景、实习经历等 | 12.5 px | 想让层级更分明或更紧凑 |
| 条目标题 | 学校、单位、项目名 | 11.6 px | 同上 |
| 正文要点 | 简介、条目要点 | 11.3 px | **最影响页数的一级**，溢出时优先动它 |
| 辅助小字 | 补充说明、板块导语 | 10.8 px | 灰色小字太小看不清时 |

每行右侧会显示**实际落地的 px 值**，不用靠猜。

> 两个层级是**相乘**关系：整体调到 96%，再把「正文要点」调到 110%，这一级最终就是 96% × 110%。

**三个实用套路**：

- **差一点溢出** → 只把「正文要点」降到 94%，别动整体缩放（保住标题的层级感）
- **顶部太空** → 「姓名」「头部信息」各加 5%
- **层级不分明** → 「板块标题」加 8%、「正文要点」减 4%，对比就出来了

改完点「重置分级字号」可以一键回到六层均等。

「导出主题」可把当前配色存成 JSON 发给同学；对方「导入主题」即可复刻。

## 七、成稿检查

点顶栏「检查」，逐条过一遍再投。

- 🔴 **红**：必须处理（超页、缺必填）
- 🟡 **黄**：建议处理（量化没加粗、要点过长……）
- ⚪ **灰**：提示性，默认关闭

工具的立场是**只提醒，不替你决定**。「GPA 要不要写」「成绩差怎么办」这类策略问题，规则默认关闭，需要自己在 `src/core/lint.js` 里配置。

## 八、导出

### PDF

「导出 → PDF」→ 打印窗口：

1. 目标打印机：**另存为 PDF**
2. 边距：**无** ← 最常被忽略的一步
3. 勾选：**背景图形** ← 不勾则没有底色与竖线
4. 页眉页脚：建议关掉

文件名自动带姓名，例如 `张三-简历.pdf`。

### Word（.docx）

「导出 → Word 文档」。结构完整、可直接编辑，含证件照与项目符号。

> Word 里的字号用的是磅，浏览器预览用的是像素，两者断行规则也不同，所以**不会逐像素一致**。都以「单页内、层级清晰」为准。

如果打开时 Word 提示「此文件来自网络」之类，选「启用编辑」即可；若提示格式异常，请反馈导出的文件以便排查。

### 网页（.html）

「导出 → 网页文件」。自包含单文件：样式、图片、**数据副本**全在里面。

用途：发人直接打开、静态托管、以及**当备份**——哪天浏览器数据清了，重新导入它即可恢复。

### 备份数据（.json）

「导出 → 备份数据」。纯数据文件，换电脑/换浏览器时用「更多 → 导入数据」恢复。

## 九、数据与隐私

- 数据只存在**你这台电脑的浏览器**里，软件**没有任何联网行为**
- 无账号、无云端、无统计埋点
- 清浏览器数据、使用隐私模式会导致丢失——**大改之前先导出一次备份**
- 若顶栏提示「本机存储不可用」，说明当前浏览器限制了本地存储，软件仍能用，但请及时导出备份

## 十、常见问题

**内容溢出一页了，先删什么？**
状态条会点名最占地方的板块。经验顺序：① 合并同类要点 ② 删掉最久远的经历 ③ 把技能 5 行并成 3 行 ④ 字号降到 96%。

**证件照什么规格？**
点击、拖入、`Ctrl+V` 粘贴都可以。软件会裁成 3:4、压成 JPEG（约 100–200KB）。尺寸可在「主题 → 证件照尺寸」里调，网页预览与导出的 Word 会**同步变化**。建议正面免冠、背景干净、脸占三分之二。

**能同时开两个页面编辑吗？**
不建议。同一份数据会被两边互相覆盖。

**预览里的文字比实际打印的小？**
预览按窗口宽度等比缩放，显示的是真实比例。打印时按 A4 原尺寸输出。

**想批量生成不同岗位的简历？**
用「版本」功能，改意向与简介即可，经历部分完全共享。

**导入旧简历后板块串了怎么办？**
用板块右上角的下拉改类型，用「＋ 添加板块」补漏，把要点剪切到正确的条目下。解析是启发式的，格式越规整越准。

**把 PDF 拖进导入窗口没反应？**
有意为之。请打开 PDF 全选复制，粘贴到弹窗的文本框 —— 比硬解析 PDF 准得多，扫描件也能用。
